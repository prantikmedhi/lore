- Codex plugin manifest and local skill metadata.
- Setup guide, client guide, examples, references, tests, security policy, GitHub workflow templates, and devcontainer config.
- Powered Mode instructions for structured research, cited answers, reports, podcasts, videos, slide decks, flashcards, quizzes, mind maps, architecture summaries, code explanations, and autonomous research workflows.
